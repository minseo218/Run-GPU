# GPU 서버 해부도

GPU 칩 안쪽부터 서버 한 대, 클러스터, 운영, 장애 진단까지 3D로 배우는 학습 페이지입니다. 파일 하나(`index.html`)로 되어 있고, 브라우저에서 바로 열면 됩니다.

## 구성 (30단계)

| 부 | 내용 |
|---|---|
| 들어가며 | AI 작업에 GPU가 필요한 이유 |
| GPU 칩 안쪽 | SM과 코어, 메모리 계층과 병목, 실행 모델(심화), 데이터 타입과 정밀도 |
| 1부 서버 한 대 | 부품, PCIe, NUMA, NVLink·NVSwitch, 연결 표(topo -m) 읽기, P2P·GPUDirect, MIG·가상화 |
| 2부 서버 여러 대 | 분산 학습과 집합 통신, InfiniBand, DPU, 클러스터 구조, 스토리지와 데이터 로딩, 전력과 냉각 |
| 3부 운영 | 소프트웨어 스택, Slurm, 쿠버네티스, 추론 서빙, 모니터링, 구축 검증, 장애 대응, 느리거나 멈출 때 진단, 성능 튜닝(스텝 시간 쪼개 보기), 대규모 학습의 장애와 복구 |
| 마무리 | 종합 설계 실습(70B 학습 클러스터), 마지막 점검 |

- 단계마다 장면 카드, 3D, 연습용 터미널(명령 ↔ 3D 연동), 확인 문제가 있습니다.
- 위쪽 `증상` 버튼: 증상을 고르면 먼저 볼 명령과 연습할 단계·시나리오로 바로 갑니다.
- 진도는 브라우저(localStorage)에만 저장됩니다.

## 열기

```bash
open index.html
```

three.js r128을 CDN(cdnjs, jsdelivr)에서 불러오므로 인터넷 연결이 필요합니다.

## 참고

숫자와 설명은 NVIDIA 공식 문서 등을 기준으로 확인했고, 각 단계의 '자세히' 패널 맨 아래에 출처가 있습니다. 상황판의 성능·시간 값 중 "예시"나 "어림"으로 표시한 것은 이해를 돕기 위한 단순화한 계산입니다.
